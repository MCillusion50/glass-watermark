# 玻璃水印 · Glass Mark

给照片加一条液态玻璃质感的相机参数水印。纯静态页面，无后端，打开即用。

## 功能

- 读取照片 EXIF：机型、焦距、光圈、快门、ISO、GPS 坐标
- 水印机型按 iPhone 15 / 16 / 17 / 18 Pro Max 的相机规格切换，可手动选镜头
- 玻璃用 WebGL 实时渲染：圆角 SDF 折射、7 路色散、45° 边缘高光
- 可调：折射、厚度、模糊、色散、浓度、大小、左右、上下
- 画质增强（unsharp + 局部对比），可开关
- 导出 JPEG（长边 2560），iOS 上长按保存到相册

## 部署

纯静态，任意静态托管都行（GitHub Pages / Vercel / Netlify）。无需构建。

## 隐私

全部计算在浏览器本地完成，照片不会上传到任何服务器。
